# Studio Veríssimo — versão Vercel

Projeto Next.js preparado para publicação na Vercel.

## Publicação recomendada

1. Crie um repositório vazio no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. Na Vercel, clique em **Add New > Project**.
4. Importe o repositório do GitHub.
5. Confirme o framework **Next.js** e clique em **Deploy**.

O arquivo `vercel.json` já contém as configurações necessárias de instalação e build.
